# Activer le site sur GitHub Pages

Le déploiement pousse le build Next.js sur la branche **`gh-pages`**.

## Réglage obligatoire (une fois)

1. Ouvre : https://github.com/Jason54jg/La-toscane/settings/pages
2. **Build and deployment → Source** : choisis **Deploy from a branch**
3. **Branch** : `gh-pages` / dossier `/ (root)`
4. Enregistre

## URL

https://jason54jg.github.io/La-toscane/

> Si tu vois encore le README : la source est encore `main` (Jekyll). Passe bien sur `gh-pages`.
